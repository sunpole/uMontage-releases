# uMontage — публичные релизы

uMontage — инструмент автоматизации допечатной подготовки монтажной формы в CorelDRAW.

Публичный репозиторий содержит только проверенные пользовательские релизы, инструкции, release notes и новости. Исходный код, рабочие тестовые материалы, клиентские CDR/PDF/PNG и внутренняя документация разработки остаются в приватном репозитории.

## Стабильная линия

Текущий стабильный выпуск: **uMontage v1.0.0 · bridge API 11**.

Один и тот же релизный ZIP проверен реальной установкой и cold start на:

- CorelDRAW 2024 — executable major 25, file version 25.0.0.230;
- CorelDRAW 2026 — executable major 27, file version 27.1.0.129.

Заявленный диапазон совместимости установщика и архитектуры: **CorelDRAW major 19–27**. Полевое подтверждение публикуется отдельно для реально проверенных версий.

## Что делает uMontage

uMontage создаёт и обновляет монтажную форму, рассчитывает геометрию листа и зоны печати, строит служебные метки, шкалы и подписи, работает с CMYK и реальными spot/Pantone-красками, сканирует краски документа и помогает повторять производственный монтаж по единым правилам вместо ручной рутины.

Интерфейс работает как Docker-панель CorelDRAW, а расчёт и построение выполняются через VBA bridge.
