# uMontage — публичные релизы

Этот репозиторий содержит только проверенные установочные пакеты uMontage для
CorelDRAW и документы для пользователей.

Исходный код, рабочие GMS, тестовые CDR, внутренние задачи и документация
разработки хранятся отдельно в приватном репозитории.

## Где скачать

Готовые версии публикуются во вкладке [Releases](../../releases). До первой
публикации здесь нет установочного пакета.

## Проверка пакета

Каждый релиз содержит:

- ZIP-пакет установки;
- `manifest.json` с версией и совместимостью CorelDRAW;
- `CHECKSUMS.sha256`;
- инструкцию установки и отката.

Перед установкой сверьте SHA-256 архива с файлом контрольных сумм из того же
GitHub Release. Не загружайте uMontage из неофициальных источников.

## Поддержка

Вопросы о конкретной опубликованной версии и сведения об исправлениях находятся
в описании соответствующего Release.
