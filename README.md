# uMontage — публичные релизы

Этот репозиторий содержит только проверенные установочные пакеты uMontage для
CorelDRAW и документы для пользователей.

Исходный код, рабочие GMS, тестовые CDR, внутренние задачи и документация
разработки хранятся отдельно в приватном репозитории.

## Новости uNews

Этот репозиторий публичный, поэтому [uNews](https://github.com/sunpole/uNews)
автоматически находит подтверждённые заметки о релизах в папке
[`news/`](news/). uNews сам проверяет и ставит публикации в Telegram-очередь
через GitHub Actions. Здесь нет Telegram-токенов и отдельного workflow
публикации.

Датированная заметка и её изображение добавляются для готового публичного
релиза или для отдельно подтверждённого публичного изменения процесса
разработки, которое уже реально работает и не раскрывает private source,
field-fixtures или локальные данные пользователя. Внутренние незавершённые
checkpoint и неподтверждённые полевые кандидаты не публикуются.

## Где скачать

Готовые версии публикуются во вкладке [Releases](../../releases). До первой
публикации здесь нет установочного пакета.

## Проверка пакета

Каждый релиз содержит:

- ZIP-пакет установки;
- `manifest.json` с версией и совместимостью CorelDRAW;
- `CHECKSUMS.sha256`;
- инструкцию установки и отката.

Перед установкой сверьте SHA-256 архива с файлом контрольных сумм из того же
GitHub Release. Не загружайте uMontage из неофициальных источников.

## Поддержка

Вопросы о конкретной опубликованной версии и сведения об исправлениях находятся
в описании соответствующего Release.


## uMontage Control

В разработке uMontage используется единый GitHub-first центр управления:
`uMontage.cmd`. Он объединяет синхронизацию с GitHub, тесты, сборку
Release-пакета, безопасный `PlanOnly`, release rehearsal и формирование
короткого диагностического отчёта.

Локальные отчёты создаются во временной папке Windows с уникальным именем до
миллисекунд и PID процесса. Они не блокируют меню Control и удаляются после
закрытия соответствующего Блокнота.

Исходный runner и внутренние development-скрипты остаются в приватном
репозитории. Публично фиксируются только подтверждённые возможности,
пользовательские релизы и безопасные новости.
