В uMontage появилось подтверждённое обновление рабочего процесса: единый
uMontage Control v1 для разработки и проверки Windows/CorelDRAW-версии.

Что сделано:
— один запуск объединяет статус, GitHub Sync, тесты, сборку Release-пакета и PlanOnly;
— Safe release rehearsal выполняет безопасную цепочку sync → tests → build → PlanOnly;
— короткий отчёт для ChatGPT открывается без блокировки меню;
— временные отчёты получают уникальное имя с миллисекундами и PID и удаляются после закрытия;
— protected stable GMS остаётся отделён от рабочего GMS и защищён контрольной суммой.

Что изменилось в работе:
— больше не нужно вручную копировать длинные PowerShell-цепочки;
— логика команд хранится и обновляется через GitHub;
— для продолжения разработки достаточно короткого диагностического отчёта вместо полного консольного лога.

Статус:
Control v1 уже используется в рабочем цикле uMontage; GitHub Sync, отчёты,
сборка alpha.10-пакета и безопасный PlanOnly подтверждены.
