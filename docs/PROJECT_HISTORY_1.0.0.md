# Путь uMontage к v1.0.0

v1.0.0 появился не как одно большое переписывание, а как длинная серия маленьких проверяемых шагов. Цель была не просто «сделать новую панель», а получить рабочий производственный инструмент, который можно безопасно обновлять, устанавливать и проверять на реальных версиях CorelDRAW.

## От старого GMS к новой архитектуре

Существующий стабильный GMS был сохранён как защищённая rollback-база. Новая ветка развивалась отдельно: HTML/JavaScript Docker стал пользовательским интерфейсом, а VBA остался производственным движком внутри CorelDRAW.

Bridge получил собственный API и проверку совместимости UI/VBA. К v1.0.0 он зафиксирован на API 11.

## Производственная логика

Постепенно в новую оболочку были перенесены и проверены:

- создание монтажной формы;
- геометрия листа, чистого поля, захвата и направляющих;
- заголовки и служебные рамки;
- реальные spot/Pantone-краски CorelDRAW;
- CMYK, печатные краски и подсчёт пластин;
- кресты, шкалы, подписи, образцы и МБР;
- сканирование красок реального CDR;
- управляемое обновление уже созданной формы;
- слои и порядок производственных объектов.

Вместо фиктивных данных проверка всё больше переносилась на реальные документы и реальные палитры CorelDRAW.

## Надёжность интерфейса

Docker получил диагностику соединения с CorelDRAW, поиск точного runtime VBA-проекта, проверку bridge version/API, восстановление последней корректной конфигурации сеанса и отдельное состояние обновлений.

Полевые тесты помогли исправить в том числе кодировки русских сообщений, поведение реального runtime GMS и различия между названием коммерческого выпуска CorelDRAW и executable major.

## Установка и безопасность

Отдельной большой частью работы стал release/install pipeline.

Появились:

- автоматический поиск установок CorelDRAW;
- поддерживаемый диапазон major 19–27;
- определение major по реальной версии CorelDRW.exe;
- PlanOnly без изменения файлов;
- backup и rollback;
- защита legacy GMS;
- проверка SHA-256;
- manual installer для нестандартных каталогов;
- developer bootstrap для чистого ПК;
- field updater для рабочего GMS.

Это позволило тестировать установку как пользовательский продукт, а не как ручное копирование файлов разработчика.

## uMontage Control и GitHub-first процесс

Для ежедневной работы появился `uMontage.cmd` — единый Control-центр. Он свёл в одно меню GitHub sync, все тесты, сборку release package, PlanOnly, safe rehearsal, установку релизного ZIP, field update, bootstrap и guarded publish.

Одновременно проект получил VERSION.json, release manifest, статические contracts и CI. Финальный rehearsal v1.0.0 сообщил 411 проверок в локальных наборах contracts и завершился полным PASS.

Тот же архив прошёл:

2. перенос без пересборки;

На рабочем CorelDRAW 2026 дополнительно подтверждены реальный документ, скан Pantone/process-красок и обновление управляемой формы.

## Что сознательно осталось на будущее

Во время финальной проверки было замечено, что переключение структуры слоёв уже существующей формы требует отдельной миграционной логики. Вместо рискованного изменения за минуту до релиза эта работа сознательно перенесена в v1.1.0.

Это и есть принцип release-процесса uMontage: стабильный релиз фиксируется, а следующая архитектурная правка получает собственную версию, тесты и полевое подтверждение.
