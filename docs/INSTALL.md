# Установка uMontage

## Перед установкой

1. Скачайте ZIP, SHA-256 и manifest из одного GitHub Release.
2. Сверьте SHA-256 архива.
3. Полностью закройте CorelDRAW.
4. Не смешивайте addon и GMS из разных версий.

## Обычная установка

1. Распакуйте ZIP в обычную доступную для записи папку.
2. Запустите `tools\Install-uMontage.cmd`.
3. Подтвердите запрос администратора Windows.
4. После успешной установки запустите CorelDRAW обычным способом.
5. Откройте **uMontage > Open uMontage**.

Для v1.0.0 в верхней части Docker должны отображаться:

`uMontage v1.0.0 bridge.11`

`VBA подключён · API 11`

## Совместимость v1.0.0

Полевой тест готового релизного ZIP подтверждён на:

- CorelDRAW 2024 — major 25 / 25.0.0.230;
- CorelDRAW 2026 — major 27 / 27.1.0.129.

Архитектурный диапазон установщика: major 19–27. Версии внутри этого диапазона, которые ещё не прошли отдельный реальный cold-start тест, считаются целевыми по совместимости, но не field-confirmed.

## Защита установки

Установщик определяет фактическую установку CorelDRAW, создаёт backup существующего addon/work GMS, проверяет SHA-256 и пытается выполнить rollback при ошибке.

Защищённый legacy GMS не перезаписывается релизным установщиком и остаётся отдельной точкой отката, если он уже установлен.

## Нестандартный путь

Для нестандартной установки CorelDRAW используйте `tools\Install-uMontage-Manual.ps1`. Сначала запускайте его в режиме `-PlanOnly`, чтобы проверить целевые каталоги без изменения файлов.
