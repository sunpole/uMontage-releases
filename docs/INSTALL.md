# Установка

Инструкция для конкретной версии лежит в её GitHub Release. Не смешивайте
аддон и GMS из разных версий: устанавливайте только комплект из одного
проверенного архива.

Перед обновлением закройте все окна CorelDRAW. Если установщик создаёт backup,
сохраните его до завершения полевой проверки.
