# Политика публикации uMontage

## Что публикуется

Только собранные и проверенные пользовательские пакеты.

Каждый стабильный Release должен содержать:

- ZIP-пакет;
- отдельный SHA-256-файл архива;
- release manifest;
- инструкции установки и отката;
- описание совместимости и field-confirmed сред;
- известные ограничения.

Внутри самого ZIP хранится `CHECKSUMS.sha256` для значимых файлов пакета.

## Что не публикуется

- приватный исходный репозиторий;
- development-fixtures и клиентские CDR/PDF/PNG;
- локальные рабочие каталоги и backup;
- токены, секреты и персональные конфигурации разработки.

Реальный field GMS входит только в проверенный пользовательский пакет как исполняемая часть релиза.

## Перед публикацией

1. Source checkpoint синхронизирован с GitHub.
2. Версия/UI/VBA/API проходят consistency checks.
3. Safety-contracts проходят полностью.
4. Release package собирается один раз.
5. Automatic и manual installer проходят PlanOnly.
6. Пакет устанавливается как готовый ZIP.
7. Выполняется обычный cold start CorelDRAW.
8. Для каждой заявленной field-confirmed версии фиксируется реальный smoke-тест.
9. SHA-256 установленного кандидата и архива сохраняются в release evidence.
10. После финальной проверки пакет не пересобирается.

## Каналы

- **Prerelease** — alpha/beta/rc и полевые кандидаты.
- **Latest** — только подтверждённый стабильный выпуск.

## Изображения новостей

Для release/news допускаются только реальные изображения работы uMontage: Docker, реальный документ, реальный экспорт, queue/publish evidence. AI-сгенерированный или вымышленный интерфейс не используется как доказательство релиза.
