# Политика публикации uMontage

## Что публикуется

Только собранные и проверенные пользовательские пакеты. Каждый пакет обязан
иметь manifest, SHA-256 и инструкцию установки/отката.

## Что не публикуется

- исходники VBA и JavaScript;
- рабочие `_work.gms`;
- CDR, PDF, PNG и другие тестовые материалы;
- внутренние журналы, резервные копии, токены и конфигурация разработки.

## Перед публикацией

1. Версия проходит полевую проверку на заявленной версии CorelDRAW.
2. Установщик определяет фактическую папку работающего CorelDRAW.
3. Проверяются контрольные суммы архива и каждого значимого файла.
4. Проверяется чистая установка и откат.
5. В описании Release указываются поддерживаемые версии CorelDRAW, изменения,
   известные ограничения и исходный commit приватного репозитория.

## Каналы

- **Prerelease** — полевые alpha/beta-кандидаты.
- **Latest** — только подтверждённый стабильный выпуск.
