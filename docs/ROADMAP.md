# Roadmap uMontage

## v1.1.0 · bridge API 12

Следующий эксплуатационный релиз.

План:

- preflight перед производственными операциями;
- строгая политика overprint для process black;
- корректная миграция существующей формы между режимами слоёв;
- уточнение UI: SINGLE = один общий служебный слой + отдельный слой «Макет»;
- защита от дублей и потери пользовательского макета при 5→2 и 2→5;
- regression-тесты для create/update и старых документов.

## v1.2.0 · bridge API 13

- таблица производственных меток;
- детерминированный порядок и управление составом;
- расширение production-mark workflow.

## v1.3.0

- именованные пользовательские пресеты;
- доработка полного рабочего цикла;
- дальнейшее сокращение ручных действий оператора.

## v2.0.0

Следующий крупный архитектурный и продуктовый цикл. Решения v2 принимаются после того, как линия 1.x накопит достаточно реальной производственной эксплуатации.
