# uMontage v1.0.0

**Bridge API:** 11  
**Source checkpoint:** `7b785744a374745c8fce390cf21381debfc85454`  
**Release ZIP SHA-256:** `6B92592AE64FB673EF408C9C85681EB528AF5C69078D7C1AC4CD40E9E946515A`

v1.0.0 — первый стабильный выпуск новой Docker-архитектуры uMontage после большой серии alpha-полевых проверок, переработки VBA bridge, интерфейса, установщика, контроля версий и release-процесса.

## Что вошло

- Docker-интерфейс CorelDRAW с подключением к VBA bridge API 11;
- создание и управляемое обновление монтажной формы;
- расчёт геометрии формы, листа, захвата, чистого поля и направляющих;
- системные служебные spot-краски;
- работа с реальными Pantone/spot-палитрами CorelDRAW;
- сканирование красок реального документа, включая spot, process и предупреждения для неподходящих объектов;
- производственные кресты, шкалы, подписи, образцы и МБР;
- управляемые слои и настраиваемый порядок;
- восстановление последней корректной конфигурации сеанса;
- диагностика HTML/JS, CorelDRAW Application, GMSManager, runtime project и bridge;
- встроенная проверка обновлений;
- защищённый installer с PlanOnly, backup, SHA-256 и rollback;
- отдельный manual installer для нестандартных путей;
- developer field update и bootstrap;
- uMontage Control — единый запуск sync, tests, build, rehearsal, install и publish;
- VERSION.json и единая проверка согласованности версии UI/VBA/API;
- GitHub CI и статические safety-contracts.

## Полевое подтверждение

Один и тот же ZIP с SHA-256 `6B92592A…6515A` был установлен без пересборки и проверен после обычного cold start на двух реальных средах:

- **CorelDRAW 2024** — executable major 25, file version 25.0.0.230;
- **CorelDRAW 2026** — executable major 27, file version 27.1.0.129.

На обеих средах подтверждены запуск Docker, bridge API 11, runtime project `uMontage_v03_work`, создание/обновление формы и работа с реальными красками документа.

Финальный safe rehearsal прошёл последовательность:

`sync → tests → build → automatic PlanOnly → manual PlanOnly`

и завершился `SAFE REHEARSAL PASS`.

## Совместимость

Установщик допускает CorelDRAW Windows major 19–27.

Field-confirmed в v1.0.0: **major 25 и major 27**.

## Известное ограничение

Переключатель режима слоёв `Раздельно / Один общий слой` сохраняет выбранную настройку, но v1.0.0 не гарантирует полноценную миграцию уже существующей формы между двумя структурами при последующем обновлении. Для новой формы выбранный режим применяется при создании.

Исправление и уточнение модели слоёв вынесены в **v1.1.0**. Пользовательский слой «Макет» должен оставаться отдельным, а режим SINGLE будет описываться как один общий **служебный** слой.

## Контроль целостности

Релиз публикуется вместе с ZIP, отдельным SHA-256-файлом и manifest. Защищённый legacy GMS остаётся rollback-базой и не заменяется релизным установщиком.
